# dnangelus.github.io

Personal landing page for DNAngeluS (Lucio Moya Farina), served at https://dnangelus.ar.

Static HTML and CSS, no build step. Styled with the DNAngeluS design system: `assets/dna.css` holds the `dna-*` component classes and `index.html` defines the tokens.

Project demos live in their own repos and are mounted on the same domain, for example `/curvar/`.
